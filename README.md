# PERA Experience Workshop デモ

「AIPC Experience Workshop」の社内外向け案内ページです。外部ライブラリや画像を使用せず、`index.html` だけで動作します。

## デモの開き方

1. このリポジトリをダウンロード、またはクローンします。
2. `index.html` をダブルクリックしてWebブラウザで開きます。

簡易Webサーバーを使用する場合は、リポジトリのフォルダーで次のコマンドを実行してください。

```powershell
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 操作方法

1. トップ画面の「参加を申し込む」を押します。
2. お名前、メールアドレス、参加区分を入力します。
3. 「申し込みを完了する」を押すと、受付完了メッセージが表示されます。

## 注意事項

この申込フォームは画面表示と操作確認のためのデモです。入力内容は保存・送信されません。実際に申し込みを受け付けるには、フォーム送信先となるシステムとの連携が必要です。
