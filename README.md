# Step1 作らせる

想定時間：15分

AIにお願いして、ワークショップの案内Webページを作ります。

## やってみよう

次の文章をコピーして、AIのチャットに貼り付けて送信してください。

```text
「AIPC Experience Workshop」の案内Webページを作って。
日時は2026年10月23日13:00〜15:00。生成AI・データ分析・AIエージェントを体験するイベントです。
参加申込ボタンを付けて、スマホでも見やすいシンプルなデザインにして。
細かい点はお任せします。確認が必要な場合を除き、途中で止まらず、index.htmlの作成・動作確認・修正まで進めて。
```

完成したら、index.htmlをブラウザで開いて確認しましょう。
