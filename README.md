# Step1 作らせる
想定時間15分

社内外向け「PERA Experience」の案内Webページを作ってください。

以下の内容を含めてください。

・タイトル：AIPC Experience Workshop  
・日時：2026年10月23日 13:00から15:00  
・内容：生成AI、データ分析、AIエージェントの体験  
・参加ボタン  

デザインは企業向けで、シンプルかつ先進的にしてください。
HTML、CSS、JavaScriptを1つのHTMLファイルにまとめ、外部ライブラリや外部画像を使用せず、1ファイルだけで動作するようにしてください。
PCとスマートフォンの両方で見やすいレスポンシブデザインにしてください。
参加ボタンを押すと、名前、メールアドレス、参加区分を入力できる申込画面が開き、送信後に受付完了メッセージが表示されるようにしてください。


追加プロンプト１
エグゼクティブけのイベントに見えるように、もう少し高級感のあるデザインに変更してください。
内容は変えず、文字量を減らしてください。


追加プロンプト２
このワークショップで体験できることを３つのカードで表示してください。
１．AIに作らせる　　
２．AIに分析させる　　
３．AIに仕事を任せる
